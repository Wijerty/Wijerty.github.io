# Квест ко дню рождения

Статический сайт-квест: задание → подсказка, где спрятан QR-код → скан камерой → следующее задание → финал.
Без сборки и без сервера: чистые HTML/CSS/JS.

```
index.html              квест (все экраны — один файл)
admin.html              служебная: генератор QR-кодов для печати
assets/js/config.js     ← ЕДИНСТВЕННЫЙ ФАЙЛ, КОТОРЫЙ НУЖНО РЕДАКТИРОВАТЬ
assets/js/app.js        логика: маршруты, проверка ответов, прогресс
assets/js/confetti.js   анимация конфетти
assets/css/style.css    оформление (палитра — в самом верху, в :root)
assets/img/             сюда класть фото для подсказок
```

## Как это работает

1. Катя получает **торт с QR-кодом**. Сканирует его — открывается главная: приветствие и кнопка «Начать».
2. Жмёт «Начать» → сразу подсказка, где искать первый код. Задания на этом шаге нет.
3. Находит код в месте из подсказки, сканирует → открывается **задание**.
4. Выполняет вживую, ответ говорит тебе, жмёт «Выполнено» → новая подсказка.
5. И так двенадцать раз. Потом — секретный тринадцатый и финал.

На сайте ничего вводить не нужно: правильность ответа оцениваешь ты, кнопка просто двигает квест дальше.

Прогресс хранится в `localStorage` — можно закрыть вкладку, сесть в метро, вернуться, квест продолжится с того же места.

**Перескочить нельзя.** Порядок держится на QR-кодах: следующий этап открывает только его собственный код. Код от 4-го этапа на 2-м даст «Рано», уже пройденный — «Здесь ты уже была», чужой QR — «Код не наш».

## Что заполнить

Всё в [`assets/js/config.js`](assets/js/config.js).

**Места уже расставлены** — 12 обычных этапов плюс скрытый 13-й. У каждого в `reward.where` стоит своя подсказка. Осталось вписать сами задания: поля `title` и `task.text`. Над каждым блоком есть комментарий с напоминанием, куда ведёт его подсказка.

### Секретный 13-й этап

У последнего этапа стоит `secret: true`. Такой этап **не считается в счётчике**: до самого конца квест показывает «12 / 12», а на двенадцатом — полную линию прогресса и надпись «Где искать последний код». Катя уверена, что всё закончилось. Но в месте «Сладких снов» лежит код секретного этапа, и он ведёт к 13-му, настоящему последнему месту.

Это место нужно вписать самому — в `reward.where` тринадцатого этапа сейчас заглушка.

### Музыка в задании

Если у задания указать `task.audio`, на экране появится проигрыватель:

```js
task: {
  text: 'Включай и танцуй.',
  audio: 'assets/audio/67.mp3',   // файл положить в assets/audio/
  audioTitle: '67'                // подпись рядом с кнопкой
}
```

Файл кладётся в `assets/audio/`. Если файла нет, вместо названия появится «Файл не найден». Музыка сама останавливается при переходе к следующему экрану.

Для каждого этапа:

| Поле | Что это |
|---|---|
| `title` | заголовок задания |
| `task.text` | текст задания |
| `task.button` | надпись на кнопке. Не указана — будет «Выполнено» |
| `task.hint` | подсказка по кнопке «Нужна подсказка». Пустая строка — кнопки не будет |
| `reward.where` | **где искать следующий QR-код** — уже заполнено |
| `reward.title` / `text` | короткий отклик после нажатия «Выполнено» |
| `reward.image` | необязательно: `assets/img/место.jpg` — фото места |
| `token` | код в ссылке QR. Меняй на свои, если хочешь |

Этапов может быть сколько угодно — просто копируй блок в массиве `steps` и ставь следующий `id`. Прогресс-бар и админка подхватят новое количество сами.

Если будешь менять число этапов, поправь отсчёты в `reward.text` («Осталось четыре», «Шесть из двенадцати») и в `intro.text` — они привязаны к двенадцати.

Финальный текст — в блоке `finale`. Имя, палитра и заголовок — в `meta` и в `:root` внутри `style.css`.

## Как выложить в интернет

QR-кодам нужен реальный адрес, поэтому сайт должен быть в сети. Проще всего — Netlify Drop:

1. Открыть <https://app.netlify.com/drop>
2. Перетащить туда папку `kate_dr` целиком
3. Получить адрес вида `https://что-то.netlify.app` — это и есть адрес квеста

Альтернативы: GitHub Pages, Vercel, Cloudflare Pages — подойдёт любой хостинг статики.

## Можно ли печатать коды, пока задания не готовы

Да. В QR-коде зашит только адрес сайта и короткий токен — например `https://адрес/#/gms36`. Тексты заданий лежат в `config.js` на хостинге и подгружаются в момент, когда Катя открывает ссылку. Дописывай задания хоть за час до начала: перезалил `config.js` — коды показывают новое.

**Три вещи, которые нельзя менять после печати:**

1. **Адрес сайта.** Коды ведут на конкретный домен. Если сайт переедет — вся пачка станет макулатурой.
2. **Токены** (`token` у этапов и у `finale`). Это и есть то, что зашито в код.
3. **Количество и порядок этапов.** Тексты меняй сколько угодно, но если вставить новый этап в середину, соответствие «код → место» поедет, и коды придётся перепечатывать.

Осторожно с Netlify Drop: **повторное перетаскивание папки создаёт новый сайт с новым адресом.** Чтобы обновлять тот же сайт, заведи бесплатный аккаунт и загружай обновления внутрь уже созданного проекта (Deploys → Drag and drop), либо используй GitHub Pages, где адрес постоянный.

Файл `_headers` в корне запрещает браузеру кэшировать страницу и конфиг — иначе телефон мог бы показать версию, сохранённую при первой проверке, без свежих заданий. На Netlify это работает само; на GitHub Pages файл игнорируется, там кэш живёт около десяти минут — просто не обновляй конфиг впритык к началу.

## Как напечатать QR-коды

1. Открыть `адрес-сайта/admin.html`
2. Поле «Адрес сайта» заполнится само — проверить, что там боевой адрес
3. **Распечатать всё** — каждый код уйдёт на отдельную страницу
4. Разрезать и разложить по местам, описанным в `reward.where` предыдущего этапа

Печатать нужно 13 кодов.

| Код | Куда кладётся |
|---|---|
| «На торт» | **на торт** — ведёт на главную, кода у него нет |
| `gms36` | «Ебанный крот Монти» |
| `w9c3q` | «Твоя очередь убирать» |
| `y3ue8` | Где бежит вода |
| `xfd9h` | Гарри Поттер |
| `9v852` | Другая реальность |
| `wn555` | «Одну каточку» |
| `jzuts` | Начинается на У |
| `u8u2k` | Там, где высоко |
| `s55uh` | Где чёрт ногу сломит? |
| `4gxaf` | Где курится кальян? |
| `gmxjk` | То, что лучше не открывать — **замотать шпагатом** |
| `4kvvm` | Сладких снов — **секретный**, она думает, что квест окончен |
| `ede2r` | 13-е секретное место → финал |

Код кладётся в место из подсказки **предыдущего** этапа — подсказка показывается после выполнения задания.

Под каждым QR напечатан короткий код — резервный вход на случай, если камера не справится (на сайте есть кнопка «Ввести код вручную»).

QR для первого этапа печатать не обязательно: этап 1 открыт с главной.

## Проверить перед днём рождения

```bash
cd /Users/kirill/kate_dr && python3 -m http.server 4321
```

Если порт занят — значит сервер уже запущен в другом окне.

Открыть <http://localhost:4321> — с телефона в той же Wi-Fi сети адрес будет `http://<ip-мака>:4321`.

Сбросить прогресс: открыть `сайт/#/reset`, либо кнопка на `admin.html`, либо `questReset()` в консоли.

**Обязательно пройди весь квест сам с телефона** — от главной до финала, сканируя настоящие распечатанные коды. Заодно проверишь, что в местах ловит интернет.
